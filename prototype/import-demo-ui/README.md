# 原型 · AI Presentation Studio「导入演示」流程

> **原型（throwaway prototype，非生产代码）。** 回答的问题：在现有界面上新增「导入演示」功能，应该长什么样、放在哪里、状态怎么流转。

## 怎么打开

- 直接双击 `prototype.html`（无需服务器），或
- 在本目录运行 `node render-prototype.mjs` 重新生成 `screens/` 下的逐屏截图。

浏览器打开后，用底部黑色切换条（`←` `→` 键或点击）在 12 个屏幕之间翻页，`prototype.html?screen=7` 可直达某一屏。

## 设计依据

`reference/` 下 4 张截图截自本机正在运行的现有应用（http://127.0.0.1:4318）：

1. `01-home.png` 首页（项目中心）
2. `02-new.png` 新建演示页
3. `03-preview.png` 安全预览页（打开现有项目，只读查看）
4. `04-edit.png` 编辑模式

既有页面（屏幕 1–4）按截图原样复现，未重新设计；新增界面（屏幕 5–12）全部用截图中已有的组件拼装：白色大圆角卡片、黑底药丸主按钮（绿色文字）、白色描边药丸按钮、灰色禁用态、绿色步骤芯片与选中描边、大写灰眉题、等宽字体技术计数、绿/黄/红状态胶囊语言。

## 边界（未加入）

未加入：图层列表、多选、页面增删与排序、新增文本框/图片、自由拉伸、裁剪、动画时间轴、模型选择、聊天窗口。侧栏保持现有「项目中心 / 新建演示」两项，未加新导航项。文案全部使用正式用词：导入演示、导入检查报告、完全可编辑、部分可编辑、暂不支持、已锁定：这个元素不可编辑。

## 附件样式（ElevenLabs tokens）的应用方式

截图是既有页面的唯一依据，因此未改动任何现有页面的配色与布局；附件的 token 用在新增部件的细节上并与现有风格重合：发丝级分隔线（stone #ebe8e4 系）、smoke/ash 灰阶的辅助文字层级、9999px 药丸按钮与胶囊、黑色实心 + 白色描边的唯一按钮层级、Geist Mono/等宽字体做技术微文案（文件大小、页码、计数）、克制的低透明度阴影、留白优先。与附件不同处（如白底 #ffffff 卡片、粗体标题）以截图为准。
