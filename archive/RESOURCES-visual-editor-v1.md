# AI 设计编辑产品 Resources

## Knowledge

- [Open Design README](https://github.com/nexu-io/open-design)
  产品定位、核心页面、Skill、Design System、模板和导出能力的总览。用来理解可借鉴的产品结构，而不是照搬全部代码。
- [Open Design Architecture](https://github.com/nexu-io/open-design/blob/main/docs/architecture.md)
  官方系统拓扑与数据流。用来识别哪些模块属于大型平台能力，哪些可以从 MVP 中删掉。
- [Open Design Skills Protocol](https://github.com/nexu-io/open-design/blob/main/docs/skills-protocol.md)
  Skill 文件结构、输入参数、实时调节参数和输出协议。用来设计后续的轻量 Skill 适配层。
- [Open Design Changelog](https://github.com/nexu-io/open-design/blob/main/CHANGELOG.md)
  当前产品已经具备的人工编辑、检查器、上传和调节能力。用来避免把已有功能误当成差异点。
- [GrapesJS Documentation](https://grapesjs.com/docs/)
  开源拖拽式 Web Builder 框架。第一版用它实现画布、组件选择、样式修改和 HTML/CSS 导出，避免自研编辑器内核。
- [Next.js Installation](https://nextjs.org/docs/app/getting-started/installation)
  官方项目脚手架和本地运行要求。用来搭建产品外壳。
- [Next.js Deployment](https://nextjs.org/docs/app/getting-started/deploying)
  官方部署方式。用来完成可分享的面试 Demo。

## Wisdom (Communities)

- [Open Design GitHub Discussions](https://github.com/nexu-io/open-design/discussions)
  观察用户问题、维护者决策和功能争议；后续也可以发布自己的作品获取反馈。
- [Open Design GitHub Issues](https://github.com/nexu-io/open-design/issues)
  查找真实 bug、编辑体验问题和新手任务，用来做竞品问题库与需求证据。
- [GrapesJS GitHub Discussions](https://github.com/GrapesJS/grapesjs/discussions)
  遇到画布、组件或导出问题时，优先查找框架社区的真实解决方案。
