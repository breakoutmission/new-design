MVP 边界速查

迷茫时只看这一页：第一版是否仍在解决“AI 生成 HTML 后的最后 20% 微调”？

现在做

  • 3 个受控 HTML 模板
  • 编辑文字
  • 替换、缩放和裁切图片
  • 调整间距
  • 重排模块
  • 撤销、保存、导出

以后再做

  • 任意网页兼容
  • 多人协作与账号
  • 插件市场
  • 多 Agent 调度
  • 同画布编辑 PPTX/视频
  • 自研拖拽内核

遇到新想法时问 4 个问题

  1. 它是否直接帮助第一个目标用户完成核心任务？
  2. 没有它，完整闭环是否仍能跑通？
  3. 5 位测试用户中至少有几位真实提出它？
  4. 做它会推迟哪个更关键的功能？
