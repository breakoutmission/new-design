# Teaching Notes

- 用户希望中文优先、一步一步推进，不假设已有代码知识。
- 用户理解 PRD 和 MVP 的基本概念，但尚无完整产品经历。
- 项目最终服务于产品经理求职，需要真实可演示、可复盘、可量化过程证据。
- 用户希望参考 Open Design 的模板与 Skill 机制，第一版优先把 `ppt-master` 产品化。
- 用户已取消可视化 HTML 微调方向，希望尽快得到可运行的产品。
- 用户不希望把五人访谈作为开工条件，认为公开产品已经提供了足够强的需求信号。
- 本地 HTML 第一课在用户侧打开时会闪退；后续默认交付 Markdown，不要求用户打开课程 HTML。
