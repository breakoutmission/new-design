## Parent

Spec Issue #13 · ADR-0013（导入项目导出放宽）

## What to build

对来源为导入的演示项目放宽 HTML 导出：允许保留 https 图片链接（仍禁止本地 file:// 引用与任何脚本），导出的 HTML 离线打开可正常显示并翻页；PDF 导出流程不变。生成项目的导出行为保持不变（自包含检查照旧）。

## Acceptance criteria

- [ ] 含 https 图片的导入项目可成功导出 HTML，图片链接保留、离线打开正常显示且可翻页
- [ ] 导出的 HTML 不含脚本与本地 file:// 引用
- [ ] 导入项目可导出 PDF，页数与页面尺寸符合演示页面设定
- [ ] 生成项目导出行为不回退：外部资源仍被拒绝，失败提示仍清晰
- [ ] 公开浏览器测试覆盖
