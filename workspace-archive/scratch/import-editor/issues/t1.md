## Parent

Spec Issue #13（HTML 导入可视化编辑）· 原型依据：`prototype/import-demo-ui/prototype.html`（可交互，`?screen=5,6,7` 直达；截图在 `screens/`）

## What to build

打通「导入演示」的第一条完整纵向链路：首页出现「导入演示」入口 → 选择单个 .html 文件 → 经最小导入检查（文件类型与大小、基本页面识别、脚本检测）→ 展示简化版导入检查报告（判定档位 + 逐条规则结果）→ 通过检查则创建导入演示项目并进入现有安全预览 → 编辑 → 保存 → 重新打开。

本票同时**冻结三个契约**，后续票基于契约并行：上传接口的请求/响应格式、导入检查报告的 JSON 结构、演示项目记录的新增字段（来源类型、原始文件名、导入检查报告、档位）。

## Acceptance criteria

- [ ] 首页可见「导入演示」同级入口（原型屏幕 5），样式与现有首页一致
- [ ] 上传对话框（原型屏幕 6）支持点击/拖拽选择单个 .html，说明「仅支持单个自包含 HTML 文件」，可取消
- [ ] 上传合法文件后看到简化导入检查报告（结构对齐原型屏幕 7），含判定档位与逐条规则结果，可进入安全预览、编辑、保存并从首页重新打开
- [ ] 文件类型不符、超过大小上限或无法识别页面时只显示原因、不创建项目记录
- [ ] 导入项目出现在最近项目列表：项目名取文件名（去掉 .html），没有「重新生成」入口
- [ ] 原始上传文件在导入前后字节内容一致
- [ ] 上传接口格式、报告 JSON 结构、项目记录新字段已记录在本 Issue 评论中，作为后续票的契约
- [ ] 公开浏览器测试覆盖以上行为，现有全套测试不回退
