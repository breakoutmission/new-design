## What to build

补全导入检查器：把最小链路中的简化检查扩展为完整规则流水线——带优先级的启发式页面识别规则表、三档判定（完全可编辑 / 部分可编辑 / 暂不支持）映射、锁定元素清单（类别 + 数量 + 原因）、移除全部内联与外部脚本（翻页由产品页面导航接管）、CSS 动画与过渡转为静态（脚本驱动的动效按暂不支持或锁定判定）、畸形/超大文件的明确原因。在导入检查器模块缝上用固定 HTML 样本逐条验收，使规则表可以快速迭代。

## Acceptance criteria

- [ ] 页面识别规则表成文并按优先级执行，每条规则至少一个正例与一个反例固定样本
- [ ] 三档判定映射逐条验收通过；同一样本重复检查结果一致
- [ ] 部分可编辑报告包含锁定元素清单（类别、数量、原因），能支撑原型屏幕 8 的展示
- [ ] 导入副本不含任何内联或外部脚本；报告中注明已移除的脚本数量
- [ ] CSS 动画/过渡转为静态显示，报告列明处数；依赖脚本生成内容的文件判为暂不支持
- [ ] 畸形或超大文件返回明确、可读的原因
- [ ] 检查器模块测试全绿；浏览器抽样验证报告与实际编辑体验一致
