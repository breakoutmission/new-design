传统方式

内容与实现纠缠在一起

不懂前端的用户需要依赖代码、反复沟通修改，或接受无法继续编辑的静态结果。

  • 需要理解 HTML 和 CSS
  • 内容修改可能牵动页面结构
  • 生成结果难以持续维护
Studio 方式

生成与编辑形成 闭环

用户从中文材料出发，使用模板生成，再通过可视化编辑完成调整和交付。

  • 模板提供稳定的视觉基础
  • Codex 完成一次性页面生成
  • GrapesJS 保存可重新打开的项目数据
